# 风险与边界

这份文档是 StudyGate 的诚实清单。把它读完再决定要不要装。

## 一、能拦住什么

**日常使用场景下基本锁死。**

开机登录 → `Winlogon` 拉起的 `Shell` 是 StudyGate 而不是 `explorer.exe` → 你看到的是答题门而不是桌面。这条路在正常使用中无法绕过：

- 界面没有"退出""跳过""稍后"，`Closing` 事件被 `e.Cancel = true` 钉死
- 底层键盘钩子吞掉 `Esc`、`Win`、`Alt+F4`、`Alt+Tab`、`Ctrl+Shift+Esc`、`Ctrl+Esc`、`F12`
- 主进程被杀，守护进程 15 秒内拉起；守护进程被杀，计划任务 30 秒内拉起
- 判分只在前端显示"已答 7/20"，不显示实时分数，堵掉"试到 90 分"的路

## 二、拦不住什么

**这不是安全产品，是自律工具。** 下面每一条都是真的。

| 绕过方式 | 可行性 | 说明 |
|---|---|---|
| `Ctrl+Alt+Del` | 一定可以 | 系统级安全序列，任何用户态程序都拦不住。摘下后会回到登录界面；重新登录时 `Shell` 仍是 StudyGate，门会再起来。所以它不能"绕过"，只能"打断"。 |
| 安全模式 | 一定可以 | `F8` / 高级启动进安全模式，计划任务与部分策略不加载。懂的人能从这里改回 `Shell`。 |
| WinRE 命令行 | 一定可以 | 这是**故意的安全阀**。锁死在门里又忘了口令时，这是唯一出路。 |
| 换系统盘 / PE 挂载 | 一定可以 | 脱机改注册表，谁都拦不住。 |
| 强关电源再开机 | 无效 | 计划任务与 `Shell` 是持久的，重启后门还在。 |
| 拔网线 | 无效 | 全程离线，题库在本地。 |
| 猜口令 | 极难 | PBKDF2-HMAC-SHA256，200k 迭代。12 位以上含数字或符号的口令，暴力破解不现实。连续错 5 次通道锁 1 小时。 |
| 找隐藏按钮 | 无效 | 界面上没有任何提示。右下角的 `v1.0.7` 是纯文本，点了没反应，它不是入口。 |
| 删程序文件 | 无效 | 计划任务会因文件缺失而反复失败，但 `Shell` 仍指向不存在的程序 → 系统会**回落到默认 shell**。这实际上是一条逃生路径，见下。 |

### 那条"删文件就能逃"的路

`Winlogon\Shell` 指向的 exe 不存在时，Windows 会无视该值、回落到默认 `explorer.exe`。也就是说**删掉 `StudyGate.exe` 就能进桌面**。

这是设计上的取舍，不是漏洞：

- 想堵，就得把程序放进受保护目录 + 用 `AppLocker` / `WDAC` 白名单，配置复杂度陡增，且一旦配错会把系统锁死到无法自救
- 一个真想逃避作业的人，会去删文件；一个真想用电脑但有底线的人，不会
- 你要防的是"手一滑就想刷视频"，不是"有人蓄意攻破"

如果你确实需要堵这条路，安装后把 `src\App\bin\Release\net8.0-windows\` 整个目录设为 `Administrators` 独占 + 用组策略 `软件限制策略` 禁止改写。代价是你自己也删不掉，回滚必须走 WinRE。

## 三、会误伤的地方

1. **提权失败**：非管理员运行或 UAC 拒绝时，`WlxShell` 写不进去 → 降级为"只锁当前会话"。答题门仍然全屏，但你能用 `Alt+F4`…… 实际上钩子还在，仍然吞键。但重启后不再锁。`install.ps1` 已强制要求管理员。
2. **计划任务不触发**：电池策略、组策略禁用任务计划、或用户改了电源计划，会导致复查失效。主进程与守护进程仍在互保，只是失去最后的兜底。
3. **多用户机器**：`Shell` 是机器级注册表项，**所有用户**登录都会进答题门。家里共用电脑的话，其他人也会被拦。这是 `Winlogon\Shell` 的固有行为，无法只锁单用户（要按用户锁，得用 `HKCU\...\Shell` 或 `AppLocker` 按 SID，复杂度高且不可靠）。
4. **远程桌面**：`Shell` 劫持对 RDP 会话同样生效，远程登录也会看到答题门。
5. **系统更新**：某些大版本更新会重置 `Winlogon` 相关项。更新后需重跑 `install.ps1`。
6. **题库进度差异**：昆明、曲靖、大理等地市教学进度不同。题库按主流进度编排，如果你学校某单元还没讲到，删掉对应题目即可（改 `data\bank\*.json` 后重跑 `install.ps1`）。
7. **无障碍**：全屏无边框 + 吞键，屏幕阅读器与放大镜可能无法正常工作。没有做无障碍适配。

## 四、隐私

- **不落键盘内容**：`InputLock` 只是过滤按键，隐蔽口令在内存里比对后立即丢弃，不写盘、不打日志。
- **不联网**：全程零网络请求，题库本地。
- **无遥测**：不收集任何数据。
- **落盘的东西**只有四样：`vault.dat`（salt + PBKDF2 哈希 + 迭代次数）、`state.json` + `.sig`（当前阶段、解锁截止时间、尝试次数）、`shell.bak`（原 Shell 值）、题库副本。
- **题面与口令不进系统日志**。所有异常只抛不改写 `EventLog`。

## 五、卸载优先级

**安全阀高于一切功能。**

`scripts\uninstall.ps1` 不需要口令、不需要答题、不需要通过任何门。它的顺序是刻意的：

1. 先还原 `Winlogon\Shell`（保证你能进桌面，即使后面全失败）
2. 再杀进程
3. 再删计划任务
4. 再清 IFEO
5. 最后删数据

即使 2–5 全部失败，第 1 步成功你就能用电脑。这一步失败时脚本会打印手工修的命令。

进不了桌面时的唯一路径：

```
Ctrl+Alt+Del → 右下角电源图标 → 按住 Shift 点"重启"
→ 疑难解答 → 高级选项 → 命令提示符
→ powershell -ExecutionPolicy Bypass -File D:\StudyGate\scripts\uninstall.ps1
```

或直接用隐蔽口令通道（走得通时最快）。

## 六、心理设计说明

这套东西的真正机制不是"锁"，是**摩擦**：

- 想在 30 秒内打开浏览器 → 得先做 20 道题
- 做题过程中不显示分数 → 没法靠"差一点"蒙过
- 未达标只有"重考"一个按钮 → 除了做题没有别的路可走
- 换卷 → 记住答案没用，得真会

这些设计的目标不是让你永远进不去，是让"随手打开电脑"这件事变得足够贵，贵到你会先想一想"我真的现在就要用吗"。

能扛住前三天的，通常就扛住了。

## 七、一句话总结

对"手滑"和"犯懒"有效。
对"蓄意绕过"无效。
忘口令、系统崩、要重装时，请务必记得 WinRE 那条路。
